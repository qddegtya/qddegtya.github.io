{%- comment -%} A "collection" card for the "A colorful world" section. It renders the latest few entries of one collection as a small STACK of cards you flip through with the < / > arrows (or swipe / arrow keys). The front card shows the entry's teaser (or a hue placeholder); a video entry shows a play button and plays in place via the theme's own video include. Params (all required unless noted): include.items - a pre-sorted (newest first) array of collection docs include.hue - the collection's dopamine hue (a CSS colour) include.icon - captured SVG markup for the collection's glyph include.label - human name, e.g. "Reading" include.unit - plural noun for the count pill, e.g. "books" include.url - the collection's index URL (caption is a link to it) The whole card is data-driven: drop new docs into the collection and the stack updates on the next build. Cap at 5 so the pile stays light. {%- endcomment -%} {%- assign items = include.items -%} {%- assign total = items | size -%} {%- assign deck = items | slice: 0, 5 -%} {%- assign shown = deck | size -%}
